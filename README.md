# 📱 iOS Practice Projects

그동안 연습했던 iOS 프로젝트들을 정리했습니다. SwiftUI와 MVVM 패턴을 활용하여 다양한 기능을 구현해 보았습니다.  

## 🚀 Projects

### 1. ✅ ToDoList
할 일을 추가하고 완료한 태스크를 표시하며, 필요 없는 태스크는 삭제할 수 있는 간단한 To-Do 리스트 앱입니다.  
**🔹 사용한 기술:** SwiftUI Views(List, Button)

---

### 2. 🏙 CityTourKiosk
경남 진주의 대표 명소와 지역 음식을 소개하는 관광 정보 앱입니다.  
**🔹 사용한 기술:** SwiftUI, JSON Parsing, MapKit, MVVM  

---

### 3. 📚 Bookstore
도서 정보를 검색하고, 사고 싶은 책을 저장할 수 있는 앱입니다.  
**🔹 사용한 기술:** SwiftUI,CoreData, SwiftData, rest API, MVVM  

---

### 4. 🌦 MyWeather (진행 중)
현재 날씨 정보를 조회할 수 있는 앱입니다.  
**🔹 사용한 기술:** SwiftUI, rest API, MVVM
